CRUD Inventaris - Tugas Rutin 8

Cara jalanin:
1. Taruh folder "inventaris" di htdocs (XAMPP).
2. Nyalain Apache dan MySQL di XAMPP.
3. Buka http://localhost/phpmyadmin, import file inventaris_db.sql
   (tab Import) atau copy isinya ke tab SQL lalu klik Go.
4. Buka http://localhost/inventaris/

Kalau user/password MySQL kamu bukan root/kosong, ubah di config/Database.php.
